# Guessing Game CLI

A simple interactive CLI based Guessing game built with Python.

This project allows you to easily play guessing game on the command line.
## Features

- Functional Guessing game.
- Three difficulties.
- Game over due to attempts.


## Requirements
- None, all present within Python library


## Project Structure

```
guessing-game/
│
├── main.py
├── README.md
```

## Running the Project

Run the program with:

```bash
python main.py
```

or

```bash
python3 main.py
```

## Playing experience

Run the program with:

```bash
python3 main.py
```
You will be prompted to choose the difficulty, depending on the chosen one, you will have either 10, 5 or 3 attempts to get the number right, if the answer is not correct, you will be informed if the number you typed, is greater or lesser than the number randomly selected.
